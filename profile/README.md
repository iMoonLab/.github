## 🧭 About Us

iMoonLab (Intelligent Media and Cognition Group) is a research lab at **Tsinghua University, School of Software**. We focus on **intelligent media understanding**, **cognitive computing**, and **knowledge-driven AI systems**.

Our work bridges cutting-edge machine learning research with practical tools that make unstructured information structured, searchable, and actionable.

**Hyper-Extract** is an intelligent, LLM-powered knowledge extraction and evolution framework.

Transform documents into structured knowledge with one command — from simple lists and Pydantic models to complex **knowledge graphs**, **hypergraphs**, and **spatio-temporal graphs**.

- 🔷 **8 Knowledge Structures** — Model, List, Set, Graph, Hypergraph, Temporal Graph, Spatial Graph, Spatio-Temporal Graph
- 🧠 **10+ Extraction Engines** — GraphRAG, LightRAG, Hyper-RAG, KG-Gen, and more
- 📝 **80+ YAML Templates** — Zero-code extraction across Finance, Legal, Medical, TCM, Industry, and General domains
- 🔌 **MCP Server** — Expose knowledge abstracts to Claude Desktop and IDE agents via `he-mcp`
- 📝 **Obsidian Export** — Turn any graph into an Obsidian vault with `[[wikilinks]]`

```bash
uv tool install hyperextract
he parse paper.pdf -t general/academic_graph -o ./paper_kb/
he show ./paper_kb/
```
